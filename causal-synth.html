Method Comparison (DL vs REML)

DL vs REML Meta-Analysis

DerSimonian-Laird (DL) and Restricted Maximum Likelihood (REML) are two approaches to estimating between-study variance (tau-squared). DL is the most widely used but can underestimate tau-squared. REML (via Fisher scoring) is generally more accurate.

CausalSynth Tutorial

Welcome to CausalSynth, the world's first browser-based causal evidence triangulation engine. Follow these 6 steps to get started.

1
Load Example Data
Click "Load Example" in the header to populate the evidence table with multi-design data (RCT, cohort, MR, etc.). Or import your own CSV with study, design, yi, se columns.
2
Explore the DAG
Select a causal DAG template (confounding, mediation, IV, collider) to visualize the assumed causal structure. Use Edit Mode to create custom DAGs.
3
Run Analysis
Click "Run Triangulation Analysis" to pool effects within each design, compute convergence metrics, and assess causal evidence strength.
4
Read Convergence Metrics
DCI = direction concordance, MCS = magnitude consistency, BDS = bias diversity, CES = composite score. GRADE-like certainty is derived from all four.
5
Interpret Causal Correction
The CaMeA-style correction converts log-OR (or log-RR) to risk differences, revealing how baseline risk assumptions affect the pooled absolute effect. Use the slider to explore sensitivity.
6
Export Results
Copy the auto-generated Methods & Results text, export CSV data, R code, or a TruthCert JSON bundle. Use Export PDF for a print-ready report.
